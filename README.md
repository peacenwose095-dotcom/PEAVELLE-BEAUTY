# Peavelle Beauty

Peavelle Beauty is a beauty e-commerce website designed to showcase and sell beauty and skincare products online.

## About the Project

This project was created as a web development project to practice building a functional and user friendly e-commerce website.
The website includes different beauty product categories and features designed to provide users with a simple online shopping experience.
##Features
-Beauty and Skincare product listings
-Product categories
-Product details
-Search functionality
-Wishlist
-Shopping cart
-Newsletter section
-Responsive website design
-Multiple product pages

##Technologies Used
-HTML
-CSS
JavaScript

I designed and developed the Peavelle Beauty website, including the page structure, styling, product sections, navigation, and interactive features.
I also organized the project files and connected the project to GitHub for version control.
I used AI assistance as a learning and development support tool to help me understand some coding concepts, and improve parts of the project. I reveiwed and implemented the changes myself while learning through the development process.
##Project Structure
The project contains:
-HTML files for the website pages
-CSS files for styling
-JavaScript files for interactive features and product information
-Image files for the products and website content

##How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a web browser.
